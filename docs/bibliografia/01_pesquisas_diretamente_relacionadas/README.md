## 1. Escopo e Enquadramento Metodológico

Este diretório reúne as 41 obras científicas classificadas no Grupo (a) do Referencial Teórico (Itens 001 a 035 da Tabela 2 do `.docx` e Adições 110 a 115). Focam centralmente em modelagem preditiva de erosão hídrica via algoritmos supervisionados de Machine Learning (XGBoost, Gradient Boosting, Ensembles), sensoriamento remoto orbital multifonte (Sentinel-2, PlanetScope), mineração de solo exposto (GEOS3), blindagem contra vazamento de dados (Data Leakage) e validação cruzada espacial em blocos (Spatial Block CV).
